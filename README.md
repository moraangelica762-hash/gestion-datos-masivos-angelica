# Proyecto: Pipeline de Datos Masivos
## Objetivo
Transformar datos crudos de e-commerce en informacion confiable para negocio.
## Capas
- Raw: datos originales.
- Silver: datos limpios y tipados.
- Gold: datos listos para analisis.
## Preguntas de Negocio
1. ¿Cual es el revenue mensual?
2. ¿Que categoras venden ms?
3. ¿Que estados tienen mayores demoras?
